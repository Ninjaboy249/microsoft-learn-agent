# Microsoft Learn Knowledge Generator

A Streamlit application that searches and extracts documentation from `https://learn.microsoft.com/`, then creates a grounded answer with Azure OpenAI when configured. Without Azure credentials, it automatically uses the built-in extractive generator.

## Features

- Searches the public Microsoft Learn search endpoint
- Accepts only exact HTTPS `learn.microsoft.com` URLs
- Downloads pages with `httpx`
- Extracts headings, paragraphs, lists, and code blocks with Beautiful Soup
- Ranks extracted sentences against the user's topic
- Produces summaries, key concepts, section notes, examples, and references
- Uses Azure OpenAI for grounded answer generation when configured
- Falls back automatically when Azure OpenAI is not configured or unavailable
- Supports simple and compound searches
- Caches searches and pages in process memory
- Stores recent topics only in the Streamlit session

Azure OpenAI receives only the user's topic, selected mode, and text extracted from the retrieved Microsoft Learn pages. The prompt requires answers to stay within that supplied content, and references are attached from the pages retrieved by the application rather than generated by the model.

## Setup

Python 3.11 or later is required.

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

No API key is required for extractive mode.

## Optional Azure OpenAI

Set these environment variables to enable LLM-generated answers:

```powershell
$env:AZURE_OPENAI_API_KEY="your-key"
$env:AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_DEPLOYMENT="your-chat-deployment"
$env:AZURE_OPENAI_API_VERSION="2024-10-21"
```

The same names can be placed in `.streamlit/secrets.toml` for local Streamlit use:

```toml
AZURE_OPENAI_API_KEY = "your-key"
AZURE_OPENAI_ENDPOINT = "https://your-resource.openai.azure.com/"
AZURE_OPENAI_DEPLOYMENT = "your-chat-deployment"
AZURE_OPENAI_API_VERSION = "2024-10-21"
```

`AZURE_OPENAI_API_VERSION` is optional. If any required setting is missing, the application ignores Azure OpenAI and remains fully usable in extractive mode. The secrets file is excluded by `.gitignore`.

## How It Works

`tools/learn_search.py` calls the public Microsoft Learn search endpoint, deduplicates results, and rejects all external domains.

`tools/learn_reader.py` validates the URL before every request and validates the final URL after redirects. It removes site navigation and unrelated interface elements before extracting documentation text.

`agent/orchestrator.py` decides whether a topic needs one search or several focused searches, ranks results, retrieves pages, and verifies references.

`services/knowledge_generator.py` creates a structured answer with Azure OpenAI when configured. It validates model output against the application schema and falls back to ranked source sentences if configuration, the model request, or model output fails.
